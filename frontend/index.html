How to Get Your Keys
Quick setup guide.
LinkedIn Access Token
1. Go to linkedin.com/developers/apps
2. Enable "Share on LinkedIn" product
3. Go to linkedin.com/developers/tools/oauth/token-generator
4. Select app → check all scopes → Request token
Groq API Key (Free)
1. Go to console.groq.com
2. Sign up for free
3. API Keys → Create API Key
4. Copy and paste above
